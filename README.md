# 百度首页静态版

直接使用浏览器打开 index.html，无需安装依赖。

参考 https://www.baidu.com/ 的首页布局，包含顶部导航、Logo、搜索框、双列示例热搜及底部信息。文字搜索跳转百度，热搜支持切换；登录、设置、以图搜图展示静态演示说明。适配桌面和手机。

Logo 使用本地图片，中文已定制为“蕙兰做的百度”。热搜为固定示例，并非实时数据。
