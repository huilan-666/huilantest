## 安装和首次配置

1. 使用有蓝牙的 Windows 10/11 64位电脑，下载 ZIP 后全部解压。保留 _internal、models、runtime、licenses 等目录，双击 A1Recorder.exe。无需安装 Python 或 Buzz。
2. 首次通过官方渠道安装 [MuMu](https://mumu.163.com/) 和[钉钉](https://www.dingtalk.com/download)，由本人登录已经绑定自己的 A1 的账号。
3. 在工作台选择本人模拟器实例，按页面明确同意后读取自己的设备配置。需要 ROOT 时，它只针对所选模拟器，用于读取本人设备资料。
4. 对照实物输入 SN 末四位；保留手机钉钉绑定，暂时断开手机蓝牙。按提示完成 A1 开机、关机、重新开机扫描，防止连到办公室其他人的卡。最后鉴权若临时失败，保持开机后直接重试当前步骤。
5. 配置完成后可关闭 MuMu。日常下载和转写不依赖模拟器持续运行。

## 日常使用

打开 A1 并放到电脑旁，断开手机当前连接后刷新列表。可按日期/时间查找，或筛选已下载、已有稿、尚未转写。选择录音下载并本地转写，再直接下载自动 TXT；校对按需选择。

回听时可拖动进度条或用方向键调整位置。可改文字、时间和说话人，拆句/合并后保存人工校对版；自动稿保留。未保存修改提示不等于自动保存。

- TXT：日常阅读、复制和分享。
- SRT：带时间轴的字幕。
- JSON：软件读取的结构化数据。

录音下载后可离线转写，本地处理不消耗钉钉云端转写分钟数，速度取决于电脑性能。有官方免费额度时，可自行优先使用官方转写；权益和余额以本人钉钉为准。

## 分享与限制

公开 ZIP 不含任何人的设备密钥或录音。每个人必须首次配置自己的账号和卡；分享软件 ZIP 即可，个人数据目录 %LOCALAPPDATA%/A1Recorder 仅用于本人私下保存。

自动稿可能有错字及短话轮分人错误，校对可选；标签是匿名分组，真实姓名需本人确认。暂无钉钉额度自动读取/切换、导入官方稿仅重新分人或长任务断点续转。小时级真实会议和不同同事实卡首配尚未现场验收。
