# 自己使用 · 蕙兰

这里保存自用程序入口、源码和维护资料。当前电脑已经配置自己的 A1；公开程序与同事版采用同一套软件，个人配置单独保留在本机。

[下载 Windows 完整程序包](https://github.com/huilan-666/huilantest/releases/download/a1-recorder-v0.3.0-pink/A1Recorder-Windows-x64.zip) · [发布页与文件校验](https://github.com/huilan-666/huilantest/releases/tag/a1-recorder-v0.3.0-pink)

## 这台电脑继续使用

1. 下载后完整解压，双击 A1Recorder.exe，保留全部配套目录。
2. 默认读取本机 %LOCALAPPDATA%/A1Recorder 中已有配置、录音和逐字稿；本机已配置时无需重复首次配卡。
3. 电脑连接 A1 时，暂时断开手机的蓝牙连接并保留账号绑定。
4. 用日期时间查找录音，下载并按需本地转写。自动 TXT 可直接下载，也可回听校对后另存人工版；原始自动稿保留。日常不需要打开 Buzz 或 MuMu。

## 换电脑或备份

个人数据目录是 %LOCALAPPDATA%/A1Recorder，包含设备密钥、配置、录音和稿件。退出工作台后，可自行备份到私人位置；迁移到本人另一台电脑时，安装完整程序并恢复这份私人备份，勿与其他人的设备数据混用。

GitHub 公开的是程序、源码和说明，个人数据不会随程序下载。本目录不是私人资料备份。

## 维护与文件格式

[源码与开发说明](源码/README.md) · [校验与已知限制](../发布检查.md)

- TXT：直接阅读和分享逐字稿。
- SRT：带时间点的字幕，可用于字幕软件或配合视频。
- JSON：结构化文字、说话人、时间和来源信息，供程序处理；不需要为日常阅读手动打开。

自动稿可能有错字及短话轮分人错误，校对可选；标签是匿名分组，真实姓名需本人确认。暂无钉钉额度自动读取/切换、导入官方稿仅重新分人或长任务断点续转。小时级真实会议和不同同事实卡首配尚未现场验收。
