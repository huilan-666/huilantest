A1 本地录音工作台 · Windows 粉红试用版

Windows 10/11 64位，需可用蓝牙。完整解压后双击 A1Recorder.exe；保留 _internal、models、runtime、licenses 等全部目录。

首次使用
1. 通过官方渠道安装 MuMu 模拟器和官方钉钉，由本人登录已绑定 A1 的账号。
2. 选择本人的模拟器实例，在页面明确同意后读取自己的设备配置。ROOT 授权只作用于所选模拟器，用于读取应用中的本人设备资料。
3. 核对实物 SN 末四位，暂时断开手机蓝牙连接并保留账号绑定。
4. 按页面提示完成开机、关机、重新开机的扫描对照，准确辨认自己的 A1。
5. 最后鉴权临时失败可直接重试当前确认步骤。成功配置后可关闭模拟器，日常不依赖 MuMu 或 Buzz 运行。

日常使用
连接/刷新列表，按日期时间查找或按状态筛选，下载录音并选择本地转写。录音下载后可离线处理，本地模型不按钉钉云端转写分钟数计费，耗时取决于电脑性能和录音长度。
自动稿可直接下载；回听校对可选。可修改文字、时间和说话人，拆句或合并，再保存新的人工校对版。原始自动稿保留。切换稿件、退出、刷新前提示未保存修改，提示不会代替保存。
播放器支持拖动和方向键操作，同一页面只播放一条音频。断开时设备信息为上次读取的缓存。

三种导出
TXT：直接阅读、复制和分享逐字稿。
SRT：带时间轴的字幕文件。
JSON：供程序读取的结构化文字、说话人与时间信息。

模型与已知限制
内置 FireRedASR2 CTC INT8、Silero VAD 和本地分人模型，不依赖 Buzz，不包含 SenseVoice 权重。
自动文字和说话人标签可能有错，尤其短插话、噪声、多人重叠；标签不是实名识别。可按用途选择是否校对。
如有钉钉免费额度，可自行选择官方转写；权益和余额以本人钉钉为准。工具不会自动读取额度或切换，尚不支持导入官方文字后仅重新分人。
长任务中断后原音频保留，但不支持断点续转；重新生成从头处理。小时级真实会议及不同同事实卡首次配置仍需试用验证。

个人数据与分享
个人配置、设备密钥、录音、逐字稿在 %LOCALAPPDATA%/A1Recorder。换电脑前自行备份到私人位置。
公开程序包不含个人数据。每位同事首次独立配置自己的账号和 A1，请勿公开个人数据目录。
本程序不改写 A1 固件、不删除卡内录音。第三方来源及许可见 THIRD_PARTY_NOTICES.md、LICENSE_SCOPE.md 与 licenses/。
